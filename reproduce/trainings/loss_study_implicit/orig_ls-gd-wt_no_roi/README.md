# Loss Weighting Study (Implicit)

This folder is for experiments on implicit loss weighting strategies in PINN training.

## Contents
- `train_different_losscomp_wght_combinations.ipynb`: Jupyter notebook for running experiments with various loss component weight combinations.

## Optimizer(s)
- `optimizer_sep_loss.py`: Implements implicit loss weighting for PINN training by separating and adjusting the optimizer's treatment of different loss components.

## How to Use
- Use the scripts and experiment subfolders to run and analyze implicit loss weighting studies.

## Notes
- Results are saved in the corresponding experiment subfolders.
- Useful for advanced studies on loss weighting in PINNs.
