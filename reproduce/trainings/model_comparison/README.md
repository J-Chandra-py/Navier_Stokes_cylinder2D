# Model Comparison

This folder contains results and visualizations for comparing different trained PINN models.

## Contents
- **main_re40.ipynb**: Contains the model comparison analysis using trained models for the PINN vs. OpenFOAM evaluation.

## How to Use
- Review the images and result files to compare model performance.
- Use these materials for discussion or reporting in the course.

## Notes
- No training scripts or optimizers are present here; this folder is for results only.
- Useful for summarizing and presenting model comparison outcomes.

## Reference
- The origin repository and base code for all PINN trainings in this folder are from https://github.com/AdrianDario10/Navier_Stokes_cylinder2D
